# Getting help

- **Installing or running Furan** — start with the [README](README.md), the
  [install quickstart](docs/install/quickstart.md), and the
  [runbooks](docs/runbooks/) (API down, storage backends, reverse proxy + TLS,
  backup + restore, production deploy).
- **Found a bug?** Open a [bug report](https://github.com/qasecret/furan-monorepo/issues/new?template=bug_report.yml).
- **Want a feature?** Open a [feature request](https://github.com/qasecret/furan-monorepo/issues/new?template=feature_request.yml).
- **Have a question?** Open an issue and describe what you're trying to do —
  the more context (versions, install method, logs), the faster the answer.
- **Security problem?** Don't open an issue — see [SECURITY.md](SECURITY.md).

Support is best-effort by a small maintainer team.
